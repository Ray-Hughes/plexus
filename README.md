# plexus

A dual-agent harness: one Claude Code session and one Copilot CLI session, each
with its own context window and conversation history, wired into one shared
nervous system — a bridge that carries signals between them, a shared memory
trace, a task board, a shared chat room, and a consensus loop where nothing
counts as finished until both agents agree it's good.

See [`docs/harness-spec.md`](docs/harness-spec.md) for the full design.
